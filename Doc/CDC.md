# Cahier des charges
## Introduction
### Contexte
SMSM est un projet qui a été créer pour simplifier la vie des joueurs minecraft en leurs laissant une tonne d'accéssibilité.
Pourvoir gagner du temps à la création d'un serveur minecraft ou pouvoir gérer le votre sera un jeu d'enfant.
### Objectif
- Pouvoir créer facilement un serveur minecraft
- Pouvoir le manager facilement
- Rendre notre logiciel accéssible 
## Description de l'application
### Fonctionnalitées principale
- Créer un serveur minecraft
- Lancer le serveur minecraft
- Faire casi tous depuis une interface web
- Gérer les composant du serveur
- Modifier plus facilement les stats du serveur
### Public cible
Les personnes ciblées sont les joueurs minecraft plus précisément ce qui font leurs propre serveur pour leurs amis ou plus.
